# Grand-canonical anti-parallel pairing on a four-site ring

This directory holds a complete expert-mode input for `NGrandCanonical=1`
with an `OrbitalAntiParallel` table only. Run it with

```
vmc.out -e namelist.def initial.def
```

The run writes `zvo_gc.dat` (`<N>`, `<N^2>`, `<N^2>-<N>^2`) and, in
`output/`, `zvo_out_001.dat` (energy, `<H^2>`, relative variance,
`<S^z>`, `<(S^z)^2>`), the one-body, two-body and N-body Green functions,
and `zvo_anomalousg_001.dat` (pair-creation and pair-annihilation averages).

## What the input describes

The pair wave function is

    |phi> = exp( sum_ij F_ij c+_{i up} c+_{j down} ) |0>

times a Gutzwiller factor and a Jastrow factor on the ring bonds. It has
weight on every even particle number but only on configurations with equal
numbers of up and down electrons, so `2Sz 0` is required in `modpara.def`.
The sampler adds or removes one up-down pair and hops electrons without
changing their spin; `zvo_gc.dat` shows the resulting particle-number
fluctuations. `Ncond` and `Ne` do not constrain the particle number in this
mode; `NGCInitNelec` only selects the starting sector.

- `orbitalidx.def`: the 4x4 table `F_ij`, one complex parameter per pair.
  The same state written as `OrbitalGeneral` would need `F_ij/2` on the
  up-down pairs and 0 on the same-spin pairs.
- `gutzwilleridx.def`, `jastrowidx.def`: one Gutzwiller class; one Jastrow
  class on the ring bonds and a second, fixed class (value 0) on the two
  diagonal pairs.
- Hamiltonian: `trans.def` (chemical potential and complex hopping),
  `coulombintra.def`, `coulombinter.def`, `hund.def`, `pairhop.def`,
  `exchange.def`, `interall.def` and `nbodyinterall.def` (products of
  spin-flip factors that conserve `S^z` as a whole), and
  `anomalousterm.def` (an up-down pair field and its Hermitian partner).
  Every term conserves `S^z`; a term that changes `S^z` is rejected in this
  mode.
- Measurements: `greenone.def`, `greentwo.def`, `nbodyg.def` and
  `anomalousg.def` include operators that change `S^z`; their averages are
  zero.

## Anti-periodic boundaries

For the anti-periodic version of the same ring, set `NMPTrans -1` in
`modpara.def`, flip the sign of the four `Trans` rows of the bond between
sites 3 and 0, and give every row of `orbitalidx.def` a fourth column with
the boundary sign (`-1` for the pairs (0,3) and (3,0), `+1` otherwise). The
first `TransSym` pattern stays the identity. Inputs generated by StdFace
with `2Sz=0` and `phase0=180` follow the procedure described for
`NGrandCanonical` in the expert-mode manual.
